二、七大系统功能实现明细
================================================================================

【功能 1：首页控制面板 (Dashboard Sheet)】
- 顶部大标题与数据驱动标语：深邃大气科技蓝黑底色。
- 6 大实时统计卡片（带动态公式）：
  * 🦸 英雄总数: =COUNTA(Characters!A2:A100)
  * ⚡ 技能总数: =COUNTA(CharacterSkills!A2:A100)
  * 🃏 卡牌总数: =COUNTA(Cards!A2:A100)
  * 🧪 状态总数: =COUNTA(StatusEffects!A2:A100)
  * 📐 规则参数: =COUNTA(GameRules!A2:A100)
  * 📦 卡牌构筑: =COUNTA(CardPools!A2:A100)
- 8 大核心操作中心按钮矩阵（醒目色块设计）：
  1. 🦸 创建新英雄 (Create Hero)
  2. 🃏 创建新卡牌 (Create Card)
  3. ⚡ 创建新技能 (Create Skill)
  4. 🧪 创建新状态 (Create Status)
  5. 🔄 同步游戏 (Sync Game to JSON)
  6. 🔍 数据完整性检查 (Data Check)
  7. 📊 生成数值平衡报告 (Generate Report)
  8. 🚀 启动对决游戏 (Launch Web Game)

【功能 2：模板系统 (Templates Sheet)】
在 Excel 中开辟独立模板库 Sheet，预置 13 种主流机制原型：
- 英雄模板：
  * 输出英雄模板 (高攻/爆发/灼烧)
  * 防御英雄模板 (高血/反制坚壁/护盾/减伤)
  * 治疗英雄模板 (持续消耗/气血自愈)
  * 刺客英雄模板 (敏捷/高危暴击/连击追加)
  * 控制英雄模板 (极寒冰封/冰冻下回合禁行动)
- 卡牌模板：基础攻击、高费强袭、穿透破盾、战斗护盾、防守姿态、调息抽牌、附魔灼烧、能量爆发等。
- 技能与状态模板：单体斩杀、护盾壁垒、极寒冻结、剧毒跳伤。
创建时直接按需继承预设属性与效果结构！

【功能 3：全自动 ID 颁发系统 (Auto-ID)】
- 严格禁止手动输入杂乱 ID，由后端生成器依据已有记录自动生成全局唯一的递增编码：
  * 英雄: hero_0001, hero_0002, hero_0006 ...
  * 技能: skill_0001, skill_0002, skill_0006 ...
  * 卡牌: card_0001, card_0017 ...
  * 状态: status_0001, status_0008 ...
- 自动关联合成：创建新英雄时，自动同步生成对应的 skill_xxxx 与 hero_xxxx_passive，
  并自动注入初始卡组构筑（CardPools），一气呵成！

【功能 4：无代码效果编辑器 (Effect Editor)】
- 在 Cards 表与 CharacterSkills 表新增专用的主/次效果列：
  * EffectType1 (主效果) + EffectVal1 (数值)
  * EffectType2 (次效果) + EffectVal2 (数值)
  * StatusRef (关联状态)
- 配合 Excel 原生数据验证 (DataValidation) 下拉菜单，直接选择机制类型：
  [damage, heal, shield, draw_card, gain_energy, apply_status, modify_damage, steal_card, self_damage, forbid_normal_attack, conditional]
- 同步引擎自动将其编译为标准声明式 effects 数组（如 damage:4 + pierce:0.5 自动编译为
  [{"type":"damage","value":4,"pierceRatio":0.5}]），无需手写复杂 JSON！

【功能 5：一键同步游戏系统 (Sync)】
- 执行流程：
  Excel (桌面或项目) ➔ 读取解析 ➔ 编译效果 ➔ 生成 JSON ➔ 聚合 game_config.js ➔ 游戏实时生效
- 产出清单：
  + data/generated/cards.json
  + data/generated/characters.json
  + data/generated/heroes.json (已按要求生成)
  + data/generated/skills.json
  + data/generated/statuses.json
  + data/generated/gameRules.json
  + data/generated/cardPools.json
  + data/game_config.js (免跨域前端统一运行包)

【功能 6：全方位数据检查系统 (Data Check)】
- 运行 python tools/editor.py check，自动进行四重严苛体检：
  1. 主键重复性体检：检测 Characters, Skills, Cards, Statuses 表是否有任何 ID 冲突。
  2. 引用完整性体检：检测技能对应的角色是否存在、卡牌/技能引用的 statusId 是否在状态表中有效存在。
  3. 数值合理性体检：检测 HP、攻击、费用、护盾是否在合规范围（如 HP 需在 1~100 之间，费用 >= 0）。
  4. 必填字段缺失排查：检测关键数据行是否发生断层。
- 自动输出清晰的体检报告（已实现 100% PASS 零报错零告警）。

【功能 7：双端极简交互 (桌面一键批处理控制台)】
- 在 Windows 桌面提供了专属快捷工具：CardGame_Editor.bat
- 双击即可打开友好的交互式菜单控制台，普通用户只要按数字 1~8 即可完成英雄创建、卡牌设计、数据体检与同步！
