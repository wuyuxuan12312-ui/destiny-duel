# 宿命对决 - 1v1 回合制卡牌对战小游戏 (支持异地联机)

一款基于原生 Web 技术（HTML5 / CSS3 / JavaScript ES6 / Web Audio API / WebRTC P2P）开发的 1v1 回合制策略卡牌对战游戏。

**支持异地网络实时联机**，无需自建后端服务器，直接上传到任何静态个人网站（Nginx、GitHub Pages、Vercel、腾讯云COS等）即可双人跨网联机！

---

## 🌐 联机对战特性 (支持异地双人)

1. **零服务器成本 (WebRTC P2P)**：
   - 借助公用 WebRTC 信令服务建立浏览器与浏览器之间的安全直接数据通道 (DataChannel)。
   - 个人网站只需托管静态网页文件 (`.html`, `.js`, `.css`)，无需购买后端服务器、数据库或配置 WebSocket。
2. **房间号与链接一键分享**：
   - 房主点击「创建新房间」，自动生成 4 位房间码（例如 `8293`）。
   - 点击「复制邀请链接」，好友手机或电脑浏览器点开该链接（如 `https://yourdomain.com/?room=8293`）即可自动填码直连对战！
3. **真实迷雾对战 (Fog of War)**：
   - 联机模式下双方只能看到自己的手牌，对方手牌以暗纹卡背显示，保密策略心理战。
4. **确定性状态同步与防乱数偏差**：
   - 采用一致性 Mulberry32 伪随机种子同步与行动广播，保证双方客户端血量、卡牌、冷却和结算 100% 绝对一致。
5. **本地双人对战保留**：
   - 依然支持「本地双人对决」模式，方便单机面对面轮流出牌体验。

## 🎮 游戏核心规则

- **能量机制**：
  - 上限 6 点，第 1 回合初始 3 点。
  - 每回合开始恢复 3 点（未消耗能量可跨回合保留，上限 6 点）。
- **行动规则**：
  - 每回合最多进行 **1 次普通攻击**（0 能量）。
  - 每回合最多使用 **1 次角色技能**（消耗能量，冷却 2 回合）。
  - 只要手牌与能量充足，卡牌使用**次数不限**。
- **手牌与抽牌**：
  - 起手双方各抽 4 张牌，每回合开始抽 1 张牌。
  - 手牌上限 8 张。
- **数值保护机制**：
  - **护盾上限**：10 点，优先吸收攻击伤害。
  - **单回合治疗上限**：单回合最多恢复 8 HP，不能超过最大初始生命值，杜绝拖局。
  - **单次爆发上限**：单次行动伤害严格控制在 10 点以内，杜绝无脑秒杀。
  - **残局狂暴加成**：第 8 轮后伤害递增，保证 6～10 轮内决出胜负。

## 🃏 16 张核心卡牌一览

### ⚔️ 攻击卡 (4张)
1. **快速攻击 (1能)**: 造成 3 点伤害。
2. **重击 (3能)**: 造成 7 点高额伤害。
3. **穿刺 (2能)**: 造成 4 点伤害，无视 50% 护盾 (2点直接扣减 HP)。
4. **双刃斩 (2能)**: 造成 5 点伤害，自身受到 1 点反冲伤害。

### 🛡️ 防御卡 (3张)
5. **小型护盾 (1能)**: 获得 4 点护盾 (上限 10)。
6. **大型护盾 (3能)**: 获得 8 点护盾 (上限 10)。
7. **防守姿态 (2能)**: 本回合受到的所有伤害降低 40%。

### 💚 回复卡 (2张)
8. **小型治疗 (2能)**: 恢复 5 HP (单回合治疗上限 8)。
9. **冥想 (1能)**: 恢复 2 HP，抽 1 张牌。

### ✨ 特殊/策略卡 (7张)
10. **火焰瓶 (2能)**: 造成 3 伤害，施加 1 层灼烧。
11. **毒刃 (2能)**: 造成 2 伤害，施加 2 层中毒 (每层每回合末 1 伤，持续 2 回合)。
12. **能量爆发 (0能)**: 立即获得 2 点能量，但本回合不能进行普通攻击。
13. **专注 (1能)**: 抽 2 张牌，且本回合下一次伤害 +2。
14. **虚弱 (2能)**: 敌人本回合造成的伤害 -2 点 (最低不低于 1)。
15. **夺取 (2能)**: 造成 2 伤害，随机复制对手 1 张手牌到自己手牌。
16. **盾击 (2能)**: 造成 3 伤害；若自身有护盾，追加 3 伤害 (共 6 点)。

## 🚀 部署与体验方式

### 1. 上传到个人网站 (异地联机)
将项目文件夹内的全部文件（`index.html`、`style.css`、`js/` 文件夹）直接上传到你的个人网站根目录或任何子目录：
- 支持 **Nginx / Apache / Caddy**
- 支持 **GitHub Pages / Gitee Pages**
- 支持 **Vercel / Netlify / Cloudflare Pages**
- 支持 **阿里云 OSS / 腾讯云 COS / 七牛云**
**注意**：在公网部署时推荐使用 HTTPS 协议，确保浏览器的 WebRTC API 权限正常开启。

### 2. 本地测试联机
可以在同一台电脑开两个浏览器窗口（或者不同浏览器，如 Chrome 与 Edge）：
```bash
cd D:\project\card_game
python -m http.server 8080
```
- 窗口 A 访问 `http://localhost:8080` 点击「创建新房间」获得房间号。
- 窗口 B 访问 `http://localhost:8080` 输入房间号点击「加入对战」。
- 即可模拟体验完整的双人联机对决！
